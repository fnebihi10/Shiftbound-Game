# Third-party assets

The current prototype contains selected assets by Quaternius in `UnityProject/Assets/Shiftbound/ThirdParty/Quaternius/`:

- Character models and textures from [Universal Base Characters](https://quaternius.com/packs/universalbasecharacters.html) and [Ultimate Modular Men Pack](https://quaternius.com/packs/ultimatemodularcharacters.html).
- Animation source from [Universal Animation Library](https://quaternius.com/packs/universalanimationlibrary.html).

The source pack license text included in the project identifies CC0 1.0 for the character and animation packs. See `Character/License_Standard.txt` and `Animation/License.txt`. The modular character pack's official page also identifies it as CC0. Preserve source and license records when replacing or redistributing assets.

The images in `ArtDirection/` are visual planning material. They are not in-game asset renders. Do not use them as evidence of implemented graphics.
