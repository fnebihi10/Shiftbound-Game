# Production upgrade sources and provenance

Historical production pass, superseded by the owner-directed WindowsPolished restoration. Its source remains in Git history through 821ee36; removed active Unity assets are intentionally preserved there and in the local backup. Review the current main source and evidence at [WindowsPolishedPort](../WindowsPolishedPort/README.md). The descriptions below concern the historical pass.

The replacement courier uses the **Quaternius Universal Base Characters Standard** CC0 humanoid anatomy/rig already present in this repository (`UnityProject/Assets/Shiftbound/ThirdParty/Quaternius/Character/Superhero_Male_FullBody.fbx`) and CC0 hairstyle from the existing downloaded standard source archive. Existing Quaternius and source texture licensing is retained in `THIRD_PARTY.md` and the third-party directories. Clothing, textile atlas, bag, trim, footwear additions and skin-weight integration are authored in `Tools/AuthorProductionCourier.py` with Blender4.5.14LTS. Editable source is `Sources/ShiftboundCourier.blend`. No purchased assets or runtime cloth.

Constructed environment geometry and foliage are authored by `ProductionMeshKit.cs` and `ProductionCityAuthoring.cs`. Shared stone/concrete texture sources and their existing provenance remain in the repository. The new geometry adds scenery depth without adding a playable level or changing route colliders.

The mineral render colour/normal maps, enamel wear and64px HDR sky reflection in the21 pass are authored offline by `ProductionSurfaceAuthoring.cs`, using original deterministic mathematical patterns and a painted hemisphere/light palette. No downloaded or purchased source is used. The reflection is a baked approximation, not a realtime reflection probe or a claim of physically accurate city reflections. These assets add material response without generating textures or capturing reflections on the phone. Roof pergolas and their planters support the alternate world's climbing growth and remain adjacent scenery; the existing route colliders are preserved.

`DistantCity-v1.png` is an original image generated9October2026 using the built-in imagegen tool. It is integrated as distant scenery in the registered panorama shader, alongside actual near/middle city geometry. It is not a gameplay capture. Prompt: horizontally wrapping2:1 distant warm-limestone city matte viewed from35m, miniature horizon band, soft pale-blue sky/cream clouds/warm afternoon, mist below, no nearby objects/people/text/interface; complements actual geometry within200m. Image generation is not 3D character authoring or evidence of gameplay quality.

The new quiet limestone paving texture is an original generated surface; geometry supplies tile scale, joints and bevels. `IvyLeaf-v1.png` was generated10October2026 with imagegen as an isolated common-ivy leaf: five lobes, visible pale veins, neutral light, transparent background, no text or pots. It is a512px alpha cutout on folded leaf geometry, not a generated3D plant. Android imports use ASTC6x6 and mipmaps. Generation/provenance does not establish artistic acceptance.

The 11 October production pass replaces the anatomical jacket shell with an authored continuous torso, articulated sleeves and elbow reinforcement, transferred onto the retained licensed rig. Unity imports 15,187 triangles in one skinned mesh with four material types and at most four normalized bone weights. The editable Blender source and reproducible authoring script are included. Fine deformation and character art remain unfinished.

`ProductionUpgrade/Motion/Courier-*.anim` uses the retained CC0 libraries with authored Humanoid muscle curves. `ProductionMotionAuthoring.cs` reauthors takeoff, rise, fall and landing using the actual idle root orientation. `CourierMotionPolish.cs` adds speed-matched ground strides, planted stance anchors, terrain contact, opposing arms and a ballistic airborne pose that holds knee lift through the apex. These changes do not delay input or alter motor reach/collision. Foot roll, braking contact and transition quality still need refinement and device review.

`ProductionDistrictAuthoring.cs` authors collider-free streets, pavements, a mixed-use courtyard perimeter, recessed shop bays and rooted canopy beneath the existing route. Distant geometry now uses setback commercial blocks, pitched housing and terraced courts. Existing traversal colliders are checked for identical signatures. The physical-scale brick bond and normal map are original deterministic offline assets from `ProductionSurfaceAuthoring.cs`, imported with ASTC and mips for Android. The same pass corrects an authoring error in smooth interpolation that had flattened brick colour and darkened the baked sky reflection. No runtime texture generation or additional realtime lights are required. Architecture repetition and far-scene integration remain review concerns.

Sanitized historical Samsung captures and current build35 local screenshots/video are committed in [SamsungReview](../SamsungReview/README.md). Raw evidence, retained baseline APK, build outputs and tool downloads stay local under `.validation/ProductionUpgrade`, excluded from Git. Build35 has not been installed on the Samsung while device testing is paused. Desktop inspection establishes local visual changes, not Android acceptance.
